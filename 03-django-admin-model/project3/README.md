# Project 03 - Django Admin Interface

## Objective
Learn how to create a Django model and manage it through the Django Admin Interface.

## Features
- Created a Blog model
- Registered the model with Django Admin
- Created a superuser
- Managed blog entries through the admin panel
- Used SQLite as the database

## Commands Used

```bash
python manage.py startapp blog
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

- project3/

## Output

Successfully managed Blog objects using Django Admin.
